# How-to video: set a password lock, lock the unit, a wrong try, unlock. Device hv_robin.
expect 60000 [BOOT] ready
serial wiz skip
# wake it (a start ends on the idle screen): the first key does nothing else
wait 1500
key SPACE
wait 800
wait 3000
key I
wait 1500
serial idle now
wait 2500
rec Password_lock_and_unlock
caption A password lock keeps your messages private. The radio is asleep: any key wakes it.
wait 3500
key SPACE
wait 2000
caption Settings: M, then S. Then 4 (Screen & I/O): hold SYM, press S.
wait 1500
key M
wait 900
key S
wait 1500
key 4
wait 2000
caption 2: Idle splash. This page holds the lock and the idle screen.
wait 1500
key 2
wait 2500
caption 3: On + password. Type a new password, 4 to 32 characters, then Enter.
wait 1500
key 3
wait 1500
type HAZELNUT
wait 600
note 3500 MIC shows or hides the password while you type it.
wait 1200
key MIC
wait 2600
key ENTER
wait 1500
caption Type it again, then Enter. The lock is on.
wait 1200
type HAZELNUT
wait 600
key ENTER
expect 5000 [LOCK] password set
wait 2500
caption 7: Lock now. (The radio also locks by itself when it goes to sleep.)
wait 1500
key 7
expect 5000 [LOCK] locked
wait 3500
caption Locked. Messages still arrive. Any key asks for the password.
wait 1500
key SPACE
wait 2000
caption A wrong password is refused. After 3 wrong tries you must wait 30 s, then longer each time.
wait 1500
type WALNUT
wait 600
key ENTER
expect 5000 [LOCK] wrong password (1 in a row
wait 3500
caption The right password and Enter: unlocked, back where you were.
wait 1500
type HAZELNUT
wait 600
key ENTER
expect 5000 [LOCK] unlocked
wait 3000
note 5000 Do not forget the password: there is no way to read it back.
wait 5500
caption Later the radio sleeps and locks again by itself.
wait 1500
serial lock now
wait 3500
rec off
quit
