# GPS + map in a scheduled power mode (Custom: GPS visits every 15 min).
# Opening the map asks for a GPS visit; the footer says what the receiver is doing; a fix
# that arrives while the map is open re-centres it; after the fix goes stale the map opens
# on the last fix (not the saved position / card home). Tiles: build\simdata\cmap\sd.
# Run: run-script.bat scripts\gps_map.txt cmap
gps off
usb off
expect 60000 [BOOT] ready
serial pm1
expect 3000 [POWER] Balanced
# Balanced keeps the GPS on since 2026-11-14: use Custom with 15-min visits and "map wakes GPS".
serial pset gps 1
expect 3000 [POWER] Custom
serial pset mapgps 1
# The mode change starts a visit; no satellite heard (indoors) ends it after 60 s.
expect 70000 (no fix), next in 15 min
# A key first: after 15 s without input the device sleeps and the waking key is used up.
key T
wait 1500
key A
expect 3000 [GPS] visit requested (map)
expect 3000 [GPS] scheduled visit: receiver on
wait 7000
shot gps-01-searching.png
# A fix arrives while the map is open: the footer shows it and the map follows it.
gps on
wait 6000
shot gps-02-fix.png
# With the Atlas open the receiver stays on (2026-11-14: up to 12 min) so the position keeps
# up while driving. Closed, the visit ends once the fix has held 20 s.
wait 25000
shot gps-03-still-on.png
serial map close
expect 3000 [MAP] closed
expect 10000 (fix), next in 15 min
gps off
# Between visits the last fix still counts (2026-11-14: until two visits fail, 2.5 x 15 min +
# a visit): after 2 min the map opens on it as "GPS", the footer shows its age ("... 2m ago"),
# and it asks for a new visit (the receiver itself has no fresh fix).
wait 100000
key T
wait 1500
key A
expect 3000 [GPS] visit requested (map)
expect 3000 [MAP] open (GPS)
wait 7000
shot gps-04-lastfix.png
quit
