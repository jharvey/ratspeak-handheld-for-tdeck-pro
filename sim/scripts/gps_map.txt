# GPS + map in a scheduled power mode (Balanced: GPS visits every 15 min).
# Opening the map asks for a GPS visit; the footer says what the receiver is doing; a fix
# that arrives while the map is open re-centres it; after the fix goes stale the map opens
# on the last fix (not the saved position / card home). Tiles: build\simdata\cmap\sd.
# Run: run-script.bat scripts\gps_map.txt cmap
gps off
usb off
expect 60000 [BOOT] ready
serial pm1
expect 3000 [POWER] Balanced
# The mode change starts a visit; no satellite heard (indoors) ends it after 60 s.
expect 70000 (no fix), next in 15 min
# A key first: after 15 s without input the device sleeps and the waking key is used up.
key G
wait 1500
key A
expect 3000 [GPS] visit requested (map)
expect 3000 [GPS] scheduled visit: receiver on
wait 7000
shot gps-01-searching.png
# A fix arrives while the map is open: the footer shows it and the map follows it.
gps on
wait 6000
shot gps-02-fix.png
# The visit ends once the fix has held 20 s; indoors again, the footer shows the fix
# age and the next scheduled visit.
expect 40000 (fix), next in 15 min
gps off
wait 3000
shot gps-03-next.png
serial map close
expect 3000 [MAP] closed
# The fix is stale after 2 min: the map opens on it ("last fix"), and asks for a new one.
wait 100000
key G
wait 1500
key A
expect 3000 [GPS] visit requested (map)
expect 3000 [MAP] open (last fix)
wait 7000
shot gps-04-lastfix.png
quit
