  Left = inbound, Right = outbound; status under outbound
- Thread Back: middle bottom tab becomes "Back" while in thread
  Tap Back or press B → Msg Box list; V still toggles

COM PORT WITHOUT RECOMPILE
--------------------------
Editing upload_port in platformio.ini can dirty the env and force big rebuilds.
Override port on the CLI instead:

  pio run -e tdeck_pro_cooperative -t upload --upload-port COM9
  pio device monitor --port COM9 --baud 115200

BAT (repo root or copy next to project):
  upload-com.bat COM9          — upload last build only
  monitor-com.bat COM9         — serial monitor
  build-upload-com.bat COM9    — incremental build + upload

VS Code:
  Terminal → Run Task… after adding vscode-tasks-snippet.json entries to
  .vscode/tasks.json (Upload COM8 / COM9, Monitor COM8 / COM9).
  Or PlatformIO: project tasks with custom upload_port in a [env:…] that
  extends cooperative WITHOUT changing shared upload_port — better still CLI.

Optional: comment out upload_port / monitor_port in [common] so PIO auto-detects
when only one board is plugged in.
