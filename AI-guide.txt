BITMAP / COLOR CONVENTION (do not invert again)
-----------------------------------------------
  FB bit 1 = black on panel, bit 0 = white.
  setPixel(black): |= mask;  setPixel(white): &= ~mask
  Initial FB: memset 0x00 (white).
  fullRefresh: fillScreen(WHITE) then drawBitmap(..., GxEPD_BLACK).
  LVGL: c.full == 0 → black pixel. Do not use c.ch.green (LV_COLOR_16_SWAP).

KNOWN POLISH (non-blocking)
---------------------------
  - Right-column values can clip near the edge; tighten padding/columns later.
  - Footer / long strings can overlap; shorten or use two lines.
  - FB often via malloc (PSRAM fallback); OK for bring-up.
  - Partial refresh not implemented yet (always full when dirty).
