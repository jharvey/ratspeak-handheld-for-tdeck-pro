BENCH / CONSOLE TOOLS (115200, see guide §11)
--------------------------------------------------------------------------------
  pw              power status, blocker, battery, unread, LoRa rx counters
  pm0..3          mode     pset <knob> <v>   Custom knob
  bench <s>       run from battery with USB attached (charger input + its
                  watchdog off, ≤4 h, auto-off <3.55 V; boot always restores)

  rl / rl 0       RTC power log (survives resets; BOOT lines with reset reason)

  sleeptest, epdoff, audio, gpio <pin> <0|1>, iomux   diagnostics

HARDWARE (T-Deck Pro v1.1, schematic 25-09-15)
--------------------------------------------------------------------------------
  E-ink 240×320 (GDEQ031T10), TCA8418 (INT 15), CST328 (INT 12), SX1262
  (CS 3, IRQ 5, RST 4, BUSY 6, EN 46), BQ27220 0x55, BQ25896 0x6B, DRV2605
  GPS MIA-M10Q UART1 RX=44 TX=43 EN=39, backup cell MS621FE (J6, D8 + R15)
  Audio PCM5102A I2S BCK 7 DOUT 8 WS 9, rail GPIO 41; KB LED=42; motor=2
  v1.1: IO38 = T-RST, IO16 = LCD_RST, IO45 = EPD backlight PWM
  See boards/tdeck_Pro/config/BoardConfig.h

--------------------------------------------------------------------------------
WHEN ADDING FEATURES
--------------------------------------------------------------------------------
  Full files preferred. Keep cooperative green.
  Hardware power changes go through powerApply() only.
  Anything that must finish before sleeping → add a powerSleepBlocker() reason.
  Switching a chip's rail off → also park every signal line to it LOW (back-power).
  Never cut the LoRa rail with SPI lines driven; LoRa "off" = radio sleep.
  Do not re-enable force-num except inside digit-entry boxes.
  Top MENU must never map through topTabScreen() to Home.
  Settings rows: one build function per page; digits 1–9, 0 = row 10.
