HOW TO SEND (Pro)
-----------------
1. Announce (boot or Home ANNOUNCE)
2. P or bottom Peers tab → tap peer (or digit 1–9)
3. Type message → Enter
4. Serial: outcome=0 Committed + [LORA_IF] TX

HOW TO READ
-----------
Msg Box tab: conversation list (unread counts)
History (H) when implemented on selected peer
Touch peer row stays on Peers; type then Enter
