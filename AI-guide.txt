BENCH / CONSOLE TOOLS (115200, see guide §11)
--------------------------------------------------------------------------------
  pw              power status, blocker, battery, unread, LoRa rx counters
  pm0..3          mode     pset <knob> <v>   Custom knob
  bench <s>       run from battery with USB attached (charger input + its
                  watchdog off, ≤4 h, auto-off <3.55 V; boot always restores)
  usbsleep <s>    allow light sleep with a USB host (console drops while asleep)
  rxdc 0|2..8     LoRa RX duty cycle off / symbols per window   tcxo  TCXO check
  dctcxo <ms>     bench: lowest duty-cycle TCXO delay (0 auto)  fe 0|1  log RX freq error (Hz)
  clk             bench: wall clock to the us + uptime + clock source (RTC drift logging)
  rmconv [<peer>|all]  bench: list conversations / delete one / delete all (with messages)
  lock | lock now  password lock status / lock     ids  identity slots + TCP status
  contact <hex32> <name>  bench: save a contact
  sdput <len> <crc32> </path>  upload a file to the SD card (under /ratdeckpro); answers
                  "[SDPUT] ready", then reads <len> raw bytes -> "[SDPUT] ok|err".
                  Use tools/maptiles/push_tiles.py (~7 tiles/s; USB RX queue raised
                  to 17 KB in main.cpp, the 256-byte default dropped bytes)
  sdformat <bytes> ERASE-ALL   FAT32 with that cluster size (8192 for maps: one
                  header-less 8 KB tile = one cluster), then restart. COM5/COM6/COM9
                  cards formatted 8 KB on 2026-11-12 (backups of their few non-map files
                  were taken first). sdinfo prints FAT type / cluster / free.
  sdput ... <offset>  (4th value) append a piece at that offset: big files in 8 KB pieces
                  (tools/sdcard/push_files.py -> /library for MENU -> Library)
  sdls [/path]    list an SD folder (absolute card path; sdlsa = all entries, for tools)
  sdget </path>   read an SD file (<= 16 KB): "[SDGET] <len> <crc32>" + raw bytes
                  (tools/maptiles/copy_tiles.py: card-to-card copy through the PC)
  loc             GPS position line + auto-share list
  cpos [<hex32> <lat> <lon> [age min] | clear]  contacts' last positions (map markers);
                  fed by the LXMF committed-message callback (onCommittedMessage -> inboundTick)
  locshare <hex32>  share my location with a contact (as the chat menu does)
  ashare <hex32> <0|5|15|30|60> | ashare off   bench: set / stop location auto-share
  sdrm </path>    delete an SD file or an empty folder (free space updates after a
                  remount/reboot)
  The simulator's serial is line-based: sdput works there, sdget does not (binary out).
  map | map <lat> <lon> [z] | map close   offline map (key L on list screens; tiles on SD)
  sdinfo | sdarc 0|1   SD status / message archive setting (applies at next boot)
  maptest <lat> <lon>  bench: write 18 grid test tiles (z14-15) around a point to the SD card
  ev | ev 0       bench: RAM event trace (rx/tx/offer/txdone/msg-in, dup-scan/dup-idx/commit ms,
                  recovered; timer wakes fold into one mark per run; survives light sleep)
  rl / rl 0       RTC power log (survives resets; BOOT lines with reset reason)
  txp <dBm>       saved LoRa TX power (-9..22)   msg <hex32> <text>   id   name
  sleeptest, epdoff, audio, gpio <pin> <0|1>, iomux   diagnostics
  Scratch scripts used on the bench (not in repo): measure.py (matrix of power
  configs from the RTC log), stress.py (senders → sleeping receiver).

--------------------------------------------------------------------------------
  Full files preferred. Keep cooperative green.
  Hardware power changes go through powerApply() only.
  Anything that must finish before sleeping → add a powerSleepBlocker() reason.
  Switching a chip's rail off → also park every signal line to it LOW (back-power).
  Never cut the LoRa rail with SPI lines driven; LoRa "off" = radio sleep.
  Do not re-enable force-num except inside digit-entry boxes.
  Top MENU must never map through topTabScreen() to Home.
