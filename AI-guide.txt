DEVICE FACTS
------------
PSRAM: found=1 size=0 — use INTERNAL only; Settings shows "PSRAM n/a".
Heap: ~45K post-proto; ~25K post-LVGL (10-line strip when largest_int allows).
Conversation page = ConversationSelector (32B); detail = ConversationView (72B).
History page = HistoryEntry (8B each); body via requestRecord.
  StoredRecordHeader is ~104B — requestRecord capacity MUST be >= header.
Announce: boot +3s; serial a; rate-limit 5s.
Outbound: lxmfSubmit to selected MsgRow peer (g_selPeer).
Compose: 120-char buffer; printable/space/backspace; Enter sends.
  No e-ink refresh while typing (serial only).
  E21: after COMPOSE_IDLE_MS (1600) with no keys, one show_screen so
  footer shows ">text". Shares MSG_REDRAW_MIN_MS rate limit with inbox
  auto-redraw. show_screen clears g_composeDirty.
Peer select: g_selPeer cycles with p; Messages list shows > on selected.
  Opening History calls requestMarkRead for that peer.

SERIAL HINTS (line + Enter)
---------------------------
  t / t hello / t:hi   send (default ping or custom) to selected peer
  H                    toggle History for selected peer (marks read)
  p                    cycle selected peer
  c                    clear compose buffer
  a r n h m s / 1 2 3  announce / reload / next / home / msgs / settings

KEYBOARD HINTS
--------------
  type chars/space     append to compose (serial [COMPOSE])
  pause ~1.6s          one fullRefresh; footer shows ">compose"
  Backspace            delete last char
  Enter (compose nonempty)  send to selected peer, clear, redraw
  Enter (compose empty)     next screen
  a / t / H / p        shortcuts only when compose empty
