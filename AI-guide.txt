MESSAGE MODE UI
---------------
When composing OR viewing a chat thread:
  • Top + bottom bars become only "Back Up  ^" (no Home/Settings/tabs)
  • Touch either bar → leave thread / clear compose
  • Keyboard Up arrow (^) → same Back
  • B key (empty compose) → Back from thread

LIST ROWS
---------
  1> NameOrShortId
     preview or short hash on second line
Names come from announce cache; rename selected peer via serial:
  n:Alice

SETTINGS (chip-away)
--------------------
Shows Identity, Battery, LoRa, Announce, Rename hint, KB backlight hint.
Serial L toggles keyboard backlight.
