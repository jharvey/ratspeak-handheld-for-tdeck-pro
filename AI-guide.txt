PLUS-LIKE SCREEN CONTENT
------------------------
Home (Plus: identity + device + Announce)
  Identity / dest hash
  Battery, LoRa, RSSI, SNR, Paths, Links, Queued
  Ann status line
  [ Announce ] button (touch or key a)

Chats (Plus: inbox)
  Inbox N conv / unread
  Thread list (convs + announced TX targets)
  H = open thread history; type+Enter reply

Contacts (Plus: saved peers)
  Saved N — conversation peers only
  tap select, type+Enter message

Peers (Plus: discovered)
  Discovered N — AnnounceManager nodes
  tap select, type+Enter message

Settings (Plus: radio + device)
  Radio: preset, freq, TX power
  Device: announce, last TX, protocol, PSRAM

SERIAL / KEYS
-------------
1 Home  2 Chats  3 Contacts  4 Peers  5 Settings
a Announce  t ping  H history  p cycle peer  c clear compose
type+Enter send  n next tab
