OVERALL GOALS
-------------
1. Port Ratspeak to T-Deck Pro (GDEQ031T10 240x320 e-ink).
2. Keep Cooperative / Node green.
3. Standalone e-ink bring-up (not full Plus UI / not ui/lvgl import).
4. Plus-like information architecture on e-ink (5 bottom tabs).
5. After messaging + shell solid: energy reduction (sleep, duty-cycled RX).
6. Later: clean upstream-friendly history.

STANDALONE RULES
----------------
Exclude LvglApplication.cpp and ui/lvgl. Include boards/tdeck_Pro.
bindDeviceOwner() before ProtocolRuntime. Prefer full files on Windows
(patches often break on CRLF / Tortoise). ASCII only.
Single fullRefresh per screen/tab change (current policy).
GxEPD2 page_height=16; firstPage+drawBitmap; flush non-white->black.
fat_label: single stroke. Protocol BEFORE LVGL. Internal node if PSRAM size=0.
Code layout: thin main.cpp + StandaloneApp.h/.cpp.
Do not break TX/RX or cooperative while adding sleep or UI parity.

PLUS PARITY GOAL (Phase G)
--------------------------
Match T-Deck Plus standalone *structure and data*, not LCD chrome:

  Plus bottom tabs:  Home | Chats | Contacts | Peers | Settings
  Pro e-ink tabs:    Home | Chats | Cont    | Peers | Set

Adaptations:
  - Portrait 240x320 vs Plus landscape 320x240
  - E-ink full refresh on tab change; no color / no trackball
  - Keyboard + CST328 touch (no trackball hold gestures yet)
  - Fat-text shell only (no import of ui/lvgl)

Path: evolve StandaloneApp shell first (G1+). Importing Plus LVGL is a
later optional G2 and would lift the exclude rule deliberately.

DEVICE FACTS
------------
PSRAM: found=1 size=0 — INTERNAL only. OPI 8MB on silicon; fix later.
Heap: ~24K steady after UI.
Touch: CST328 @ 0x1A. Minimal read in StandaloneApp.
Battery: ~1400-1500 mAh. E-ink refresh negligible; MCU+RX dominate.

LAYOUT + TOUCH ZONES (G1 — keep in sync with code)
--------------------------------------------------
Canvas: EPD_WIDTH=240, EPD_HEIGHT=320 (portrait).

  Header:     y = 0 .. 32     title + 3px rule
  Content:    y = 36 .. CONTENT_BOTTOM
  Compose:    y = TAB_TOP - 22  (when buffer non-empty)
  Tab bar:    y = TAB_TOP .. 319

Constants (StandaloneApp.cpp):
  TAB_H   = 34
  TAB_TOP = EPD_HEIGHT - TAB_H     // 286
  TAB_W   = EPD_WIDTH / 5          // 48
  CONTENT_BOTTOM = TAB_TOP - 4
  PEERS_TOP = 104                  // list rows start
  ROW_H   = 46                     // name + optional preview

Tab touch (y >= TAB_TOP):
  x 0..47   -> Home
  x 48..95  -> Chats
  x 96..143 -> Contacts
  x 144..191-> Peers
  x 192..239-> Settings
  Same-tab tap = no refresh.

List row touch (Chats / Contacts / Peers, y >= PEERS_TOP, y < CONTENT_BOTTOM):
  row = (y - PEERS_TOP) / ROW_H  -> select peer; redraw only if changed.

History (Chats only, H key): any content tap returns to Chats list.
Home / Settings content taps: ignore (stay on tab).

TAB CONTENT
-----------
Home
  Battery, LoRa, RSSI, SNR, Paths, Links, LXMF Q, LOCAL_DEST
  Shortcut: a = announce

Chats  (former Messages)
  Convs / Unread, conversation + announced rows, compose, History (H)
  Select peer (touch / p), type+Enter TX, H = history toggle

Contacts
  Conversation peers only (no announce-only fill)
  Select + type+Enter TX

Peers
  AnnounceManager nodes only
  Select + type+Enter TX; a = announce if empty

Settings
  Radio preset name, freq, TX power, last announce/TX, protocol, PSRAM

SERIAL / KEYBOARD
-----------------
  type + pause ~1.6s   compose on glass
  Enter (nonempty)     send to selected peer
  Enter (empty)        next tab
  a / t / H / p        shortcuts when compose empty
  1=Home 2=Chats 3=Contacts 4=Peers 5=Settings
  c                    clear compose (serial)
  n                    next tab
  r                    reload rows
  Leading space avoids H/t/a/p swallowing first letter of a message.

E-INK REFRESH

Optional E24: partial for compose footer + selection marker only;
