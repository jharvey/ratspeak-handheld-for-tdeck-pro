DEVICE FACTS
------------
Board: ESP32-S3FN16R8 (16MB flash + 8MB OPI PSRAM on silicon).
PSRAM: found=1 size=0 free=0 — OPI map still broken; use INTERNAL path only.
Heap: ~44-45K free_int after proto; ~25-28K after LVGL when 20-line strip fits.
  Fragmentation: if largest_int < 9600, LvglPort falls back to 10 then 5 lines.
Conversation page returns ConversationSelector (32B each), NOT View.
  Detail: requestConversation(selector) -> ConversationView (72B + preview).
Announce: g_proto.announce(nullptr, 0); boot +3s; serial line "a"; rate-limit 5s.
Names: loadNameCache() after setStorage; resolve at Messages draw time.
Outbound: lxmfSubmit to g_msgRows[0].peer; poll + acknowledge.
E-ink: CS park with LoRa; one fullRefresh per screen change.

SERIAL HINTS
------------
Putty: type a full line, then Enter (line-oriented since E15).
  t              default body "ping from tdeck-pro"
  t hello world  custom body (max ~160 chars)
  t:hi           same (colon form)
  a              announce
  r              force reload Messages
  n / h / m / s  next / home / messages / settings (also 1 2 3)
Keyboard t = default ping only; Enter/touch cycles screens.
