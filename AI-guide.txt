NAV (G1.8)
----------
TOP: Settings (S underlined) | Home (H underlined)
BOT: Contact (C) | Msg Box (M) | Peers (P)
  widths 80 | 96 | 64 — hotkey letter underlined in label

KEYS (compose buffer empty)
---------------------------
  A  Announce     S  Settings     H  Home
  C  Contact      M  Msg Box      P  Peers
  V  View thread  N  Next peer    T  Test ping
  Enter          send if typing, else next tab
  Back (on-glass) leave message mode / clear compose
  Alt / Sym      handled by keyboard HAL (case / symbol layer)

MESSAGE MODE
------------
1. Open Contact / Msg Box / Peers
2. Select peer (tap row or N) until >
3. Type — enters message mode (footer shows text + Back)
4. Enter — TX to selected peer
5. Escape — tap on-screen Back (or clear compose)

PEER LIST AUTO-REFRESH
----------------------
On Peers screen, when announce set grows: redraw.
Throttle: at most one full e-ink refresh per 30 seconds.
Pending changes apply on next allowed window.

HOME
----

3x2 tiles (tap to toggle soft flags)
Announce button
