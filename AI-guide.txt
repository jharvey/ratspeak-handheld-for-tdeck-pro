DEVICE FACTS
------------
PSRAM: found=1 size=0 — use INTERNAL only; Settings shows "PSRAM n/a".
Heap: ~45K post-proto; ~25K post-LVGL (20-line strip when largest_int allows).
Conversation page = ConversationSelector (32B); detail = ConversationView (72B).
History page = HistoryEntry (8B each); body via requestRecord.
  StoredRecordHeader is ~104B — requestRecord capacity MUST be >= header
  (E17 used 96 and always fell back to #counter only).
Announce: boot +3s; serial a; rate-limit 5s.
Outbound: lxmfSubmit to first MsgRow peer.

  a r n h m s / 1 2 3  announce / reload / next / home / msgs / settings
