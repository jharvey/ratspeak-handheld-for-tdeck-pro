CONTACTS LIKE PLUS (G1.29)
--------------------------
Screen shows two sections:
  TRUSTED (n)     — saved contacts with display names
  RECENT PEERS (n)— announced peers (short id until named)

Save / name a peer (on-device, like Plus "Set contact name"):
  1. Open Contact tab
  2. Select peer: 1-9 or touch row
  3. Enter (empty) → "Set contact name" screen
  4. Type name (e.g. radio2)
  5. Enter → setContactName + saveNode + name cache
  6. Peer moves under TRUSTED with that name

Cancel: keyboard Up (^) or Back Up bar

Serial still works: n:Alice after selecting peer

HOW TO TEXT
-----------
Msg Box / Peers: select → type → Enter
Contacts: Enter opens name editor (not TX); use Peers/Msg Box to message

ONE-LINER
---------
G1.29: Contacts = Trusted + Recent; Enter=name/save like Plus video.
