NAMES + ID EVERYWHERE
---------------------
Contacts, Peers, Msg Box list rows:
  line1 = contact display name (or short id if unnamed)
  line2 = ID: <hex>  (+ optional preview / RSSI)

CONTACTS (G1.29+)
-----------------

SETTINGS (G1.30) — Plus-like hierarchy
--------------------------------------
Root categories (1-9 or touch, Enter opens):
  1 Identity & Device   — dest hash, firmware label (live)
  2 Screen & Input      — e-ink N/A; KB light via serial L
  3 Battery             — volts + % (live)
  4 LoRa                — ON/OFF intent, region, RSSI (Enter toggles)
  5 Network             — WiFi/TCP stubs (future)
  6 Time & Location     — GPS stubs (future)
  7 Alerts & Audio      — Audio ON/OFF (Enter toggles, live)
  8 Diagnostics         — paths, links, heap, PSRAM, uptime (live)
  9 Storage & Maint.    — heap/PSRAM; Enter on Send Announce

Back: keyboard Up (^) or touch header "< …" on sub-pages.
Tab to Settings always opens root list.

WORKING vs STUB
---------------
Live: Battery, LoRa intent+RSSI, Audio toggle, Diagnostics, Announce, names
Stub: WiFi/TCP, GPS, Theme/Dim, QR, Create Identity, Erase, Firmware check
