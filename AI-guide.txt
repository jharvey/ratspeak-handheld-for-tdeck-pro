--------------------------------------------------------------------------------
NAVIGATION
--------------------------------------------------------------------------------
Top:    Settings | Home
Bottom: Contact | Msg Box | Peers   (list screens only)

Hotkeys (list / Home / Settings — not while typing in thread):
  H Home   S Settings   M Msg Box   C Contacts   P Peers
  A Announce
  0–9 select row (Contacts / Msg Box / Peers)
  Enter on Msg Box list → open selected chat
  Enter empty on Contacts → name-edit mode
  Keyboard Up / lone Shift → Back (leave thread or settings sub-page)
  B while in thread → Back

Thread / name-edit only:
  Bottom full-width BACK (top still Settings|Home)
  Type message → Enter send
  Leave: BACK bar, keyboard Up, or B

--------------------------------------------------------------------------------
MESSAGING (important)
--------------------------------------------------------------------------------
1. Msg Box list shows conversations (1> NAME / preview). Selecting does NOT
   enable typing.
2. Tap peer (or digit + Enter) → opens THREAD (history bubbles).
3. Only in THREAD: keyboard composes; Enter sends LXMF.
4. Compose on Contacts list = rename contact (Enter saves name), not send.
5. Peers list: select / view; send from Msg Box thread after selecting peer.

If [TX] rejected Busy/Recovering: wait for radio quiet, retry; reboot frees
stuck engine. Prefer announce both ways before first message.

--------------------------------------------------------------------------------
CONTACTS / NAMES
--------------------------------------------------------------------------------
- 0> = this radio (local). Type name + Enter → saveSelfName (NVS).
- 1>… = remotes. Type name + Enter → setContactName + name cache.
- Announce moves peers trusted; names show on Msg Box / Peers / Contacts.
- If 2> won’t stick after touch: rebuild used to clamp sel — G1.46+ keeps
  selection by destination hash.
