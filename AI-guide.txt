STANDALONE RULES
----------------
Exclude LvglApplication.cpp and ui/lvgl. Include boards/tdeck_Pro.
bindDeviceOwner() before ProtocolRuntime. Prefer full files on Windows.
ASCII only. Single fullRefresh per tab change.
GxEPD2 page_height=16; firstPage+drawBitmap; flush non-white->black.
fat_label: single stroke. Protocol BEFORE LVGL. Internal node if PSRAM size=0.
Code layout: thin main.cpp + StandaloneApp.h/.cpp.

PLUS PARITY (Phase G)
---------------------
Same five sections as Plus, different chrome for e-ink portrait:

  TOP row (2 boxes):   Home | Settings
  BOTTOM row (3 boxes): Chats | Cont | Peers

No page title header — selection is shown by inverted (black) box on the
active nav button. Content fills the middle band only.

LAYOUT + TOUCH (G1.1 — keep in sync with code)
----------------------------------------------
Canvas: 240 x 320 portrait.

  TOP_NAV:   y = 0 .. TOP_H-1          TOP_H = 36
             [ Home 120px ][ Settings 120px ]
  Content:   y = CONTENT_TOP .. CONTENT_BOTTOM
             CONTENT_TOP = 40, CONTENT_BOTTOM = 276
  Compose:   y = BOT_TOP - 22 when buffer non-empty
  BOT_NAV:   y = BOT_TOP .. 319        BOT_TOP = 280, BOT_H = 40
             [ Chats 80 ][ Cont 80 ][ Peers 80 ]

List rows (Chats/Contacts/Peers):
  PEERS_TOP = 96, ROW_H = 46

Touch:
  y < 36          -> top tab by x < 120 = Home else Settings
  y >= 280        -> bottom tab by x/80 = Chats | Cont | Peers
  list content    -> peer row select
  History content -> back to Chats
  same-tab tap    -> no refresh

Active tab draw:
  draw_nav_box(..., active=true) => black fill + white label
  inactive => white fill + black border + black label

TAB CONTENT (unchanged data)
----------------------------
Home      Battery LoRa RSSI/SNR paths links Q dest announce
Chats     Convs/unread, conv+announced rows, compose, H=history
Contacts  Conversation peers only
Peers     AnnounceManager nodes only
Settings  Radio freq power announce TX protocol PSRAM

SERIAL / KEYBOARD
-----------------
  1=Home 2=Chats 3=Contacts 4=Peers 5=Settings
  n=next tab  a=announce  t=ping  H=history  p=cycle peer
  c=clear compose  type+Enter=send
  Leading space avoids H/t/a/p swallowing first letter.
